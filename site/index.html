Your coding agent, right under the cursor.

Hold Ctrl (⌥ Option on a Mac) and the left mouse button on the desktop or in a folder window, and a radial menu opens under the cursor. Pick a slice and Claude Code starts in a terminal, already in the right folder.

A folder

Start new, continue, or pick any session.

Open starts a new session and Continue the most recent one. Resume opens outward into the five newest sessions, the newest right outside the slice.

A file

Ask about a file. It is already in the prompt.

Ask About This File puts the file first in the prompt, so Claude Code reads it right away. Pin up to five saved prompts and the Ask slices open into them.

The desktop

Your recent projects, one slice away.

Recent Projects opens into the five folders you worked in last. Pick one to resume its latest session, or open it further into its sessions.

The desktop

A quick question that leaves nothing behind.

Quick Conversation answers on a card of its own that floats over your windows without taking the focus. Claude Code keeps no transcript of it, and Rondel deletes what is left once it ends.

Tray icon or menu bar

Point at the screen and ask.

Ask About a Screenshot lets you pick an area or a window (on the Mac with macOS's own picker), then asks what you want to know about it. Nothing is sent until you start.

Active Agents

See which agent needs you.

A notification when an agent asks for something, finishes or stops with an error. Active Agents lists them, those waiting first: amber waiting, green done, red stopped.

Drawn by Rondel itself.

These pictures come from the macOS app's own drawing, with made-up projects; the agents card and the themes are from Windows.

Five themes, each dark and light: Rondel, Line, Spotlight, Orbit and Petal. Dark or light can follow the system, and the accent is the theme's own, a ready-made pair or your own colors.

Made for working with agents.

  • The New Project cardA folder name, a first prompt, git init, plan mode and your templates. It remembers your last choice, so the usual project is a name and Enter.
  • Sessions, and the space they takeEvery saved Claude Code session, the largest first. Delete the ones you no longer need, into the Recycle Bin (the Trash on a Mac) or for good.
  • The keyboard all the wayDigits, arrows, Tab and Enter in the menu; Space opens a slice's items and Esc steps back. Or keep holding, move onto a slice and let go.
  • The agents cardOn Windows it keeps the running agents in sight, and can show your Claude plan's 5-hour and weekly usage limits.
  • Keeps itself up to dateIt installs a new version only when the release carries the signature of Rondel's release key. Your agents keep running.

Windows and macOS.

The same menu on both, with each one's own key and file manager. Features by platform shows what each has.

  • WindowsHold Ctrl and the left mouse button on the desktop or in File Explorer. Windows 10 and 11, x64 and ARM64. No installer, no admin rights. Not code-signed yet, so SmartScreen asks once.
  • macOSHold ⌥ Option and the left mouse button on the desktop or in Finder. macOS 15 or later, Apple Silicon and Intel. Signed and notarized by Apple. The agents card is not there yet.

No telemetry.

Rondel reads Claude Code's local session data only to show the hints and the recent sessions.

  • Open sourceMIT licensed; the code of every release is on GitHub.
  • A daily update checkOnce a day Rondel asks GitHub for its latest release, and the request carries nothing but Rondel's version. You can turn it off in Settings.
  • Events stay on your computerThe agents Rondel starts report to it on 127.0.0.1 only. Your own Claude Code settings are not changed.
  • Verified releasesEvery release lists SHA-256 checksums signed with Rondel's release key, and carries build provenance attestations.
